# AGENTS.md

Instructions for AI coding agents working on this NethServer 8 module.

## NethServer skills

General NethServer conventions live in the agent skills of the
[NethServer/agents](https://github.com/NethServer/agents) repository:
module layout, actions and events, backup and restore, UI, Containerfiles,
commits, pull requests and releases. Install them in your agent as that
repository's README explains.

Load the matching skill before you start a task, for example
`nethserver-ns8-module` to change the module code, or `nethserver-admin`
to test it on an NS8 node. Do not copy the skills' rules into this file.

## Module instructions

Add here only the instructions specific to this module, that the skills

### ns8-theme specifics

- Read [DESIGN.md](DESIGN.md) first: it explains the route takeover, the
  cookie-selected stylesheet variants and the fail-safe.
- Two Traefik routes (`<module_id>-cfg`, `<module_id>-css`) at priority
  100100 exist only while `theme.service` runs; `bin/manage-routes` owns them.
  Never add them from an action without the health check.
- `theme/dist/` is generated by `theme/build.mjs`; never edit it. Palette
  changes go in `theme/tokens/dark.json`, hand fixes in `theme/overrides/`.
- Selectors for parts of the shell that stock NS8 already draws dark are
  skipped by the `SKIP` regex in `theme/build.mjs`.
- Testing without a published image: build `theme/` in a `node` container,
  run `bin/expand-config` with the agent's Python
  (`/usr/local/agent/pyenv/bin/python3`) and fake `AGENT_*` variables, start
  nginx-unprivileged by hand, and add the routes with `api-cli`.
